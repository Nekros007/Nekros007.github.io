analyse du script :

le but de ce script c'est de gérer le service MLFLOW comme on le voit sur la capture on peut voir le status, redémarrer et sauvegarder mais ce qui nous intéresse nous c'est que le script va regarder dans le dossier /opt/tools/mlflow_ctl/plugins/ pour voir si y a des plugins et il va les importer.

On a aussi la fonction "site.addsitedir()" :

lorsque cette fonction est appelée, python exécute cet algorithme en arrière plan :
1- liste tous les éléments dans le dossier spécifié
2- ignore tous les fichiers classiques (.py,.txt, .md) et isole ceux dont le nom se termine par l'extension .pth par exemple (patch.pth)
3- pour chaque fichier .pth trouvé il ouvre et lit son contenu (normalement les fichiers .pth comporte des chemins de dossiers)
4- Quand python lit le contenu si c'est un chemin classique exemple (/var/www/) il prend cette chaîne et l'ajoute à sa liste de recherche (sys.path)
-si la ligne commence par import, python se dit ce n'est pas un chemin de dossier c'est une instruction donc python utilise sa fonction native exec()

ce que l'on va faire maintenant :
on crée un fichier .pth pour que quand on déclenche le script, python comme il voit que c'est un fichier .pth il lit son contenu et là il va tomer dans notre piège car le contenu du script commence par "import" donc python va croire que c'est une instruction et utilisé exec

voila a quoi ressemble le contenu de ce fichier :

import os : Bibliothèque standard qui permet a un programme python de parler au système linux de la machine
os.system() : prend une chaîne de caractére et l'envoie directement au shell (le terminal) de la machine, comme si je la tapais moi même dans la console
cp /bin/bash /tmp/rootbash : comme c'est root qui va effectuer cette tâche (copier son bash), j'aurais un bash avec les droits root dans le fichier rootbash dans tmp
chmod +s /tmp/rootbash : pour que quand je lane rootbash j'aurais les droits root car avec le +s le système exécutera tout le temps avec les droits de son propriétaire et dans notre cas c'est root le proprio
